# 👻 유령의 섬

무인도에 표류한 주인공이 이 섬에서 먼저 죽은 유령 **윤서**와 함께 섬의 비밀을 풀고 탈출하는 텍스트 어드벤처 게임입니다.
Python 표준 라이브러리 `tkinter`만으로 창을 띄워 동작합니다. (청년 피지컬 AI, 2026-10-15)

> 과제 조건 — 장르: 자유형 프로그램 / 주어: 유령 / 공간: 무인도 / 돌발 상황: **숨겨져 있던 조건이 뒤늦게 드러난다**

## 실행 방법

```bash
python ghost_island.py
```

Python 3만 있으면 됩니다. 추가 패키지는 필요 없습니다. 그림 파일(`*.png`)은 `ghost_island.py`와 같은 폴더에 있어야 합니다.

## 게임 소개

- **20일 제한**: 날마다 짙어지는 안개가 주인공의 몸과 기억을 갉아먹습니다. 20일 안에 탈출하지 못하면 배드엔딩입니다.
- **4개 장소 탐색**: 해변·정글·동굴·언덕을 오가며 재료와 윤서의 일지 조각을 찾습니다.
- **제작**: 재료를 모아 `횃불`(나뭇가지 + 기름통)과 `뗏목`(나무판자 3 + 덩굴 2 + 돛천)을 만듭니다.
- **체력 관리**: 이동·탐색마다 체력이 줄고, 열매·고기를 먹거나 쉬어서 회복합니다.
- **돌발 이벤트**: 장소마다 다른 동물(바다악어·멧돼지·곰·들개)을 만나 도망치거나 싸웁니다.
- **윤서와의 신뢰도**: 하루 한 번 대화할 수 있고, 신뢰도가 오를수록 대사와 힌트가 달라집니다.
